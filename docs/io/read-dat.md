# 读取 DAT 文件

`read_dat(path, shape, dtype)` 读取无文件头的二进制 DAT 文件，返回指定形状和数值类型的 NumPy 数组。

## 示例

下面以宽 640、高 512、无符号 16 位大端序的数据为例。将示例路径替换为实际文件路径。

```python
from adome import read_dat

data = read_dat(
    "IMAGE_1_256.dat",
    shape=(512, 640),
    dtype=">u2",
)

print(data.shape)      # (512, 640)
print(data.dtype.str)  # >u2
```

## 参数

| 参数 | 说明 |
| --- | --- |
| `path` | 文件路径，支持字符串和 `pathlib.Path`；相对路径以运行时的当前工作目录为基准。 |
| `shape` | 返回数组的形状。二维数组使用 `(行数, 列数)`，例如宽 640、高 512 对应 `(512, 640)`。 |
| `dtype` | 文件中数值的存储类型和字节序，使用 NumPy 数据类型或类型字符串。 |

数组按文件中的数值顺序排列；二维数组按行填充。

### 存储格式

`">u2"` 中，`>` 表示大端序，`u` 表示无符号整数，`2` 表示每个数值占 2 字节，即 16 位。

| `dtype` | 存储格式 |
| --- | --- |
| `">u2"` | 无符号 16 位大端序整数 |
| `"<u2"` | 无符号 16 位小端序整数 |
| `">i2"` | 有符号 16 位大端序整数 |
| `"<f4"` | 32 位小端序浮点数 |

## 返回值

返回 `numpy.ndarray`，其形状由 `shape` 指定，数值类型和字节序由 `dtype` 指定。

## 常见错误

- 文件不存在时，抛出 `FileNotFoundError`。
- 读取到的数值数量无法组成指定形状时，抛出 `ValueError`。
